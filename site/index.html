01 / SEND AND CHECK

How to verify a folder handoff

  1. 01

    Sign the file list

    The sender records each path, size, and SHA-256 hash. Their Ed25519 key signs the ordered list.

    handoff create ./final -k sender.key
  2. 02

    Send the folder

    Send the folder and signed file list with your usual transfer tool.

    handoff package ./final -m receipt/manifest.json -o package
  3. 03

    Verify the received folder

    The recipient sees the exact missing, changed, and extra paths.

    handoff verify manifest.json ./files -p sender.pub
