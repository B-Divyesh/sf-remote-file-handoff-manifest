PRIVACY // LOCAL FILES

See how your files stay private.

Effective 28 August 2026

Product data

The site has no account, analytics, advertising, cookies, or tracking pixels. The command-line tool has no telemetry or network code.

Browser checks

Your browser reads selected files, signed file lists, and public keys. It does not upload them or save them in site storage.

Demo data

The web demo uses bundled sample data in memory. Resetting or leaving the demo discards its current display.

Offline cache

A service worker caches public site files for offline use. It never caches files you select for checking.

Hosting logs

The host may process short-lived request and security logs needed to serve the site. This product adds no tracking identifier.

Questions

Use the public source repository. Do not include your signed file list or file contents.
