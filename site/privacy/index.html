PRIVACY // LOCAL FIRST

What stays on your machine stays yours.

Effective 27 August 2026

No collection

The website has no analytics, advertising, accounts, cookies, or tracking pixels. The CLI has no telemetry and makes no network requests.

Browser verification

Files, manifests, and public keys selected in the browser are read locally using browser APIs. Their names, contents, and hashes are not sent to us or any third party.

Offline cache

A service worker stores the public website files on your device so the verifier can reopen offline. It does not store selected handoff files. Clear the site’s storage in your browser to remove this cache.

Hosting logs

The deployment host may process ordinary short-lived security and request logs needed to serve the site. The product does not add identifiers to those requests.

Contact

Questions can be filed in the public source repository without sharing manifest or file contents.
